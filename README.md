## Quality Assurance – Urban Scooter

### Project Overview

Urban Scooter is a scooter rental application that allows users to rent scooters through its web and mobile platforms. The project focused on validating the application's functionality, requirements, and user experience across different components.

### Testing Activities

- Analyzed requirements and created a mind map to organize functionality and identify test objects.
- Created a checklist for the Order Status section of the web application.
- Validated input data against requirements using boundary value analysis, equivalence partitioning, and allowed character validation.
- Designed and executed test cases for the mobile application.
- Created a checklist to validate API functionality and behavior on the web application.
- Performed functional testing to verify application behavior against requirements and identify defects.

### Test Results

Identified several defects during testing and documented them in Jira. Some defects blocked the execution of dependent test cases, preventing further validation of certain functionalities. Despite these limitations, most of the planned tests were successfully executed, while the remaining blocked tests were documented and tracked as bugs.

**Tools & Techniques:** Mind Mapping, Checklists, Functional Testing, Mobile Testing, API Testing, Equivalence Partitioning, Boundary Value Analysis, Input Validation, Requirements Analysis, Jira.
